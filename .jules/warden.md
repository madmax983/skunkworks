## 2027-08-30 - Trace Tardis Integer Overflow (DoS)
**Threat:** The `intersect_rect` function in `graveyard/trace-tardis/src/safe_gl.rs` used unchecked addition (`a.0 + a.2`) which could cause integer overflow when using large coordinates, leading to a panic in debug builds (DoS) or wrapping behavior in release builds. Furthermore, negative values passed to `glScissor` could cause undefined behavior.
**Defense:** Replaced unchecked addition and subtraction with `.saturating_add()` and `.saturating_sub()` to ensure safe coordinate clamping. Added `.max(0)` clamps when calling `glScissor` to protect the FFI boundary from negative dimensions.
