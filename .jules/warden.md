**2024-11-20 - [Stack Overflow DoS via Value Struct Recursion]
**Threat:** The `Value` struct derived `Clone`, `PartialEq`, and `Drop` methods, which compiled to recursive logic. Since `Value` includes nested elements like `Junction` and `Superposition`, an adversary could create a deeply nested `Value` structure that results in a stack overflow when cloned, hashed, or dropped, resulting in a Denial of Service (DoS).
**Defense:** Explicitly replaced derived `Clone` and `PartialEq` with custom iterative solutions using queues to prevent deep recursion. To handle `Drop`, we added a `safe_drop(mut self)` function that dismantled the tree structure iteratively using `std::mem::replace`.
