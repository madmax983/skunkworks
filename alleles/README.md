# 🧬 Alleles - Preserved Genetic Material

This directory contains exceptional experiments that have been used in hybridization but are too valuable to delete. These are the "dominant alleles" - traits worth preserving even after they've contributed to new offspring.

## Criteria for Preservation

An experiment earns allele status when it:
- Has been successfully crossed to create hybrids
- Demonstrates unique qualities worth referencing
- May inspire future crosses or standalone revival
- Contains particularly elegant implementations

## Contents

### literary-boids
**Status**: Preserved from experiments/
**Children**: luminous-flock, phonetic-flock
**Why preserved**: Exceptional flocking simulation with literary metaphor. The spatial dynamics and emergence patterns are reference-quality.

---

**Note**: Experiments in this directory are NOT part of the workspace. They won't be built or tested automatically. To work on one, either:
1. Add it back to workspace members temporarily
2. Build directly with `cargo build -p <name>`
3. Copy to experiments/ for active development
