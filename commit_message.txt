🔒 Warden: [Unbounded File Read DoS Prevention V]

**Threat:** Unbounded file reads were identified in several graph and compiler components (`mnem-strings`, `chron-compost`, `chimera-lang`, etc.). Using `std::io::Read::read_to_string` combined with `take` incorrectly or `fs::read_to_string` directly allowed malformed, excessively large inputs to exhaust system memory and crash the application (Denial of Service).
**Defense:** Replaced calls with the memory-safe pattern `file.take(limit + 1).read_to_string(&mut content)`. Ensured explicit bounds checks where required. Also fixed tests and compilation issues around the safe usage.
**Severity:** High - prevents OOM crashes on malformed inputs.
