# 125. Miller-Physics Hybrid

Date: 2026-06-20

## Status

Accepted

## Context

The Splice Surgeon created a new experimental hybrid called `miller-physics`. This experiment crosses the discrete, rigid 3D crystalline lattice generated by filesystem structures (`crates/miller-lattice`) with the continuous soft-body constraints provided by Position Based Dynamics (`crates/physics-pbd`).

## Decision

We map the static structural crystal nodes of a codebase (the Miller lattice) into interacting particles within a physical system. The 3D hierarchical lattice is transformed into a soft-body organism where directories act as heavier particles and files act as lighter particles. The hierarchical parent-child relationships between directories and files are mapped directly to physical distance constraints. The root directory is pinned, and the rest of the structure dangles or floats.

## Consequences

- **Positive:** Enables an emergent structural codebase morphogenesis visualization, creating a bouncing, breathing physical representation of the repository's architecture as distance constraints continuously attempt to resolve.
- **Negative:** The computational cost of the Position Based Dynamics solver grows significantly with large repositories, as thousands of structural distance constraints must be resolved iteratively per frame.
