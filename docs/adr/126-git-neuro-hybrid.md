# 126. Git-Neuro Hybrid

Date: 2026-06-20

## Status

Proposed

## Context

The Splice Surgeon created a new experimental hybrid called `git-neuro`. This experiment crossbreeds the discrete, chronological commit history of a repository provided by `crates/git-associates` with the biological, chaotic firings of a Spiking Neural Network from `crates/neuro-sim`.

## Decision

We map discrete repository modifications directly to neural injection currents. The codebase history becomes the physical environment that a neural network attempts to "digest". The commit chronology and complexity (such as message length and diff size) are translated into electrical jolts applied to specific sensory neurons. The network includes massive hidden pools of neurons with dense recurrent connectivity to process the inputs.

## Consequences

- **Positive:** Produces an emergent simulation where repository history translates into a sequence of electrical storms in a synthetic brain, allowing observation of how historical code changes cause ripple effects and cognitive load in the neural pathways.
- **Negative:** Tuning the recurrent connectivity weights and injection current thresholds to prevent the network from either dying out entirely or experiencing sustained uncontrolled epilepsy requires careful manual calibration.
