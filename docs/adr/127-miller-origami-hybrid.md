# 127. Miller-Origami Hybrid

Date: 2026-06-21

## Status

Accepted

## Context

The Splice Surgeon created a new experimental hybrid called `miller-origami`. This experiment crosses the discrete, rigid 3D crystalline lattice generated by filesystem structures (`crates/miller-lattice`) with the continuous soft-body folding meshes provided by Miura origami patterns (`crates/origami`).

## Decision

We map the static structural nodes of a codebase (the `Crystal` data structure, representing files and directories) into a continuous, time-varying Miura origami grid (`generate_miura_grid` via `MiuraParams`). The hierarchical structural dependencies and file pathways act as continuous, breathing tissue that expands and contracts, translating a rigid codebase layout into an organic, breathing organism based on the Miura-ori fold.

## Consequences

- **Positive:** Enables an emergent structural codebase morphogenesis visualization, creating a breathing physical representation of the repository's architecture as the origami grid continuously folds and unfolds.
- **Negative:** The computational and rendering cost of recalculating the continuous Miura grid and mapping crystal bonds onto the vertices increases significantly for large repository structures, making the spatial wrapping visually chaotic and performance-heavy on complex codebases.
