# 152. Arthropod-Market Hybrid

Date: 2026-07-11

## Status

Accepted

## Context

The Splice Surgeon created a new experimental hybrid called `arthropod-market`. This cross explores mapping by crossing the abstract GUI interactions of `arthropod` with the continuous Double Auction physical particle system of `market-sim`.

## Decision

Cross the immediate mode UI library `arthropod` with the `market-sim` Double Auction physics grid. Clicking discrete buttons injects bouncing physical liquidity into the continuous market environment.

## Consequences

- **Positive:** Enables interactive real-time injection of continuous physical financial elements using discrete UI actions.
- **Negative:** Merges immediate mode UI logic with continuous physics simulation ticks.
