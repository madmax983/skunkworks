# 154. Arthropod-Resonance Hybrid

Date: 2026-07-11

## Status

Accepted

## Context

The Splice Surgeon created a new experimental hybrid called `arthropod-resonance`. This cross explores mapping by crossing the immediate mode UI library `arthropod` with the continuous 2D wave physics of `resonance-audio`.

## Decision

Cross the `arthropod` UI with the `resonance-audio` wave physics.

## Consequences

- **Positive:** Allows real-time interactive stimulation of continuous acoustic wave physics.
- **Negative:** Adds UI handling overhead to high-frequency acoustic wave simulation ticks.
