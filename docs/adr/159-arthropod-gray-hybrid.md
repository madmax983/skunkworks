# 159. Arthropod-Gray Hybrid

Date: 2026-07-17

## Status

Accepted

## Context

The Splice Surgeon created a new experimental hybrid called `arthropod-gray`. This cross explores interactive chemical morphogenesis by combining the immediate-mode UI library `arthropod` with the continuous thermodynamic reaction-diffusion simulation of `gray-scott`.

## Decision

Cross the immediate mode UI library `arthropod` with the `gray-scott` continuous thermodynamic reaction-diffusion simulation. Clicking discrete buttons dynamically modulates the `feed` and `kill` chemical rates in real-time, instantly forcing the continuous biological patterns to change from spots to stripes or dissipate entirely.

## Consequences

- **Positive:** Enables real-time interactive exploration and modulation of continuous morphogenetic biological models using abstract graphical controls.
- **Negative:** Merges immediate mode UI logic with continuous thermodynamic simulation ticks, coupling discrete input directly to simulation parameters.
