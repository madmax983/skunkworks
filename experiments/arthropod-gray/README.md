# Arthropod Gray

A hybrid experiment crossing `arthropod` and `gray-scott`. The immediate mode UI elements of `arthropod` are used to dynamically mutate the chemical parameters of the `gray-scott` Turing pattern simulation.

## Lineage

*   **Parent A (arthropod):** Immediate mode UI components (sliders, buttons).
*   **Parent B (gray-scott):** Continuous thermodynamic reaction-diffusion simulation.
*   **Novel Trait:** Abstract UI elements physically manipulate the environment parameters (feed rate, kill rate, diffusion) of the biological chemical simulation, allowing the user to manually "drive" the morphogenesis.

## Emergence

By interacting with the sliders, the user can steer the chemical system through different known Turing pattern domains (spots, stripes, mitosis, chaotic waves) in real time.
