# Arthropod Lattice

**Lineage:** `arthropod` × `miller-lattice`

## Concept
Interactive Codebase Crystallography. This hybrid bridges the gap between the static, procedural generation of 3D hierarchical codebase structures (`miller-lattice`) and the immediate mode GUI elements of `arthropod`.

By clicking on the screen, users can dynamically spawn new file systems "seeds" or alter the growth parameters of the 3D crystal lattice. The continuous rendering of the crystal updates in real-time as the discrete user interface provides inputs.

## Emergent Phenotype
We predict an interactive crystalline garden. Instead of just viewing a static codebase structure, the user becomes a gardener. The immediate mode UI allows for real-time pruning and planting of new hierarchical branches, creating a living 3D data structure that responds to direct manipulation.
