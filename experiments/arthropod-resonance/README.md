# arthropod-resonance

**Parents**: `crates/arthropod` + `crates/resonance-audio`
**Concept**: Interactive Acoustic Morphogenesis.

## Traits
* **Lineage from `arthropod`**: Immediate mode graphical UI buttons providing discrete interactive events.
* **Lineage from `resonance-audio`**: Continuous 2D finite-difference time-domain (FDTD) acoustic wave simulation.
* **Phenotype**: An interactive acoustic laboratory where abstract button clicks directly inject physical acoustic pressure into a continuous wave tank. The user dynamically "plays" the wave tank via UI elements, triggering localized plucks and oscillators.

## Quick Start
```bash
cargo run -p arthropod-resonance --release
```
