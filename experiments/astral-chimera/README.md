# Astral Chimera 🧬🪐

**"The Music of the Spheres becomes the Logic of the Spheres."**

This experiment is a hybrid of **Celestial Cantata** (Orbital Mechanics) and **Chimera Lang** (Genetic Programming).

## Concept

In `astral-chimera`, the execution of genetic code is not driven by a linear clock, but by **Orbital Mechanics**.
- **Planets** are organisms carrying `ChimeraVM` genomes.
- **The Sun** is the center of the system.
- **The Radar** (Time) sweeps around the system.
- When the Radar intersects a Planet, its VM executes a step.

Gravity alters the orbits, which alters the timing of execution. A stable orbit creates a predictable loop. A chaotic orbit creates unpredictable execution patterns.

## Lineage

- **Parent A**: `experiments/celestial-cantata` (N-body physics, Radar sequencer)
- **Parent B**: `experiments/chimera-lang` (Virtual Machine, Opcodes)
- **Emergent Trait**: **Orbital Scheduling**. The physical arrangement of matter determines the scheduling of computation.

## Usage

```bash
cargo run -p astral-chimera
```

## Controls

- `q`: Quit simulation.
