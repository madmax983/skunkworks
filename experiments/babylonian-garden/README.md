# 🧬 Babylonian Garden 🌿

> "The code is written in the clay of history."

A hybrid experiment combining **Sexagesimal Mathematics** (from `babylonian-forecaster`) with **L-System Procedural Generation** (from `l-system-garden`).

## Concept

This experiment visualizes the Git history of the repository as a procedurally generated "Hanging Garden".

*   **DNA:** Each plant's genome is derived from a Git Commit Hash.
*   **Translation:** The hash is converted into a **Sexagesimal (Base-60)** number.
*   **Morphology:** The digits of the Sexagesimal number determine the L-System production rules (branching patterns, angles).
*   **Leaves:** The leaves of the plant are Cuneiform characters representing the genetic code.

## Lineage

*   **Parent A:** `experiments/babylonian-forecaster` (Sexagesimal math, Cuneiform rendering)
*   **Parent B:** `experiments/l-system-garden` (L-System logic, Turtle graphics)
*   **Hybrid:** `experiments/babylonian-garden`

## Controls

*   `Tab`: Next Plant (Commit)
*   `Space`: Grow (Increase Iterations)
*   `r`: Reset Growth
*   `Arrows`: Pan Camera
*   `+/-`: Zoom
*   `q`: Quit

## Phenomenon

Observe how the structure of the code history manifests as biological forms. "Spaghetti code" might literally produce tangled vines, while clean commits produce symmetrical ferns.
