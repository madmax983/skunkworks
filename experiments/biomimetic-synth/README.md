# Biomimetic Synth 🧠🔊

A spiking neural network synthesizer where the audio output is directly generated by the population dynamics of Izhikevich neurons.

## Concept

This experiment simulates a network of 100 Izhikevich neurons with STDP (Spike-Timing-Dependent Plasticity) learning.
The "sound" is not a sine wave or a sample, but the raw electrical activity of the network:
- **Low Frequency Hum**: The mean field potential (average voltage) of the population.
- **High Frequency Clicks**: Individual spike events.

The network exhibits emergent behaviors like synchronization, bursting, and seizures, which result in complex, evolving textures.

## Controls

- **Click & Drag**: Stimulate neurons under the cursor with current injection.
- **R**: Reset neuron parameters to "Chattering" mode (rhythmic bursting).

## Technical Details

- **Neuron Model**: Izhikevich (Regular Spiking, Fast Spiking, Chattering).
- **Plasticity**: STDP (Potentiation if pre-before-post, Depression if post-before-pre).
- **Audio Engine**: Runs on a separate thread (or mimics audio timing if `rodio` is unavailable).
- **Visualization**: Real-time voltage heatmap and synaptic connectivity using `macroquad`.

## Running

```bash
cargo run -p biomimetic-synth
```

To enable real-time audio output (requires `alsa-sys` or compatible backend):
```bash
cargo run -p biomimetic-synth --features audio
```
If audio backend is unavailable, the simulation runs in "Ghost Mode" (visuals only).
