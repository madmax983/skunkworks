# chaos-tank
**Lineage:** `experiments/chaos-pendulum` × `experiments/ripple-tank`

**Concept:** Acoustic Chaos. A physical double-pendulum simulation where the tip of the chaotic pendulum swings dynamically over a 2D physical acoustic wave tank. As the pendulum's tip moves fast enough, it strikes the wave tank, plucking the simulated acoustic field.

**Phenotype:** The chaotic, mathematically unpredictable orbits of the double pendulum perturb the water surface, creating complex, chaotic, non-repeating wave interference patterns.

**Control:** Drag the yellow tip with the mouse into the box to perturb it yourself.
