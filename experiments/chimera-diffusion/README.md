# 🧬 chimera-diffusion

**Lineage:** `crates/gray-scott` × `experiments/chimera-lang`

## Concept
Chemical Genetic Organisms. Agents equipped with `ChimeraVM` brains navigate a Reaction-Diffusion substrate (Turing patterns).

## Novel Trait
**Chemical Evolution:**
The agents use sensor opcodes to "smell" the U and V chemical gradients and use effector opcodes to inject or consume chemicals. They must evolve `Dna` sequences to survive in the toxic V-chemical zones or farm the U-chemical, translating genetic instructions into physical chemical interactions with the continuous environment.

## Execution
```bash
cargo run -p chimera-diffusion
```
