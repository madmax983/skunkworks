# Chimera Fluid 🧬💧

> "The water remembers what the code has done." - Genesis (The Oceanographer)

**Chimera Fluid** is a hybrid experiment combining the 4D Fluid Simulation from `hyper-fluid` with the biological agents of `chimera-lang`.

It simulates a population of "Chimera Agents" swimming inside a 4D Hypercube where fluid density and velocity are driven by system metrics. The agents must "swim" (apply force) against the currents generated by your computer's workload.

## ⚠️ Requirements

*   **Graphical Display**: This experiment requires an OpenGL context (X11, Wayland, Windows, macOS). It **cannot** run in a headless environment (like a server or simple container).
*   **System Metrics**: It reads CPU/RAM usage to drive the simulation.

## 🚀 Run

```bash
cargo run -p chimera-fluid
```

> **Note:** If you encounter `XOpenDisplay() failed!`, it means you are running in a headless environment. You must use a desktop environment to view this experiment.

## 🧬 Lineage

This experiment is a direct cross between:

*   **Parent A**: `experiments/hyper-fluid` (The Environment)
    *   Provides the `Grid4D` density field and the SPH/PBD particle physics engine.
    *   Inherits the system-load-driven distortion (CPU = Agitation, RAM = Viscosity, Swap = Gravity).
*   **Parent B**: `experiments/chimera-lang` (The Life)
    *   Provides the `ChimeraVM` and genetic code execution.
    *   Agents run a genetic program that senses local density/gradient and decides how to apply force vectors (Swim).

## ⚗️ Novel Traits

*   **4D Hydrodynamic Locomotion**: Agents do not just move; they must apply force vectors in 4 dimensions (X, Y, Z, W) to navigate the fluid.
*   **Metabolic Swimming**: Movement costs energy. Efficient swimmers survive; thrashing agents starve.
*   **System-Driven Currents**: High CPU usage agitates the fluid, making swimming chaotic. High RAM usage increases viscosity, slowing everything down. High Swap usage increases gravity, pulling agents into the depths.

## 🎮 Controls

*   **WASD / Arrow Keys**: Rotate and Zoom the 4D Camera.
*   **System Load**:
    *   **CPU Usage**: Agitation (Random Kicks).
    *   **RAM Usage**: Viscosity (Damping).
    *   **Swap Usage**: Gravity Strength.

## 🧪 Implementation Details

*   **Physics**: Hybrid Particle-Grid Fluid Simulation (SPH-like density + Grid-based pressure).
*   **Biology**: ChimeraVM agents with custom I/O channels for Sensing Gradient and Applying Force.
*   **Rendering**: 4D Hypercube projection to 3D using `macroquad`.
