# Chimera Git 🧬🖥️

**Cross:** `chimera-lang` × `git-harmonograph`

## Concept
Codebase Foraging Organisms. Agents running `ChimeraVM` traverse the Git commit history, evolving to find the most efficient path through the repository's refactoring history.

The agents read Git commit diff sizes and entropy as environmental inputs to their VM. They evolve genetic sequences to navigate the codebase history efficiently, treating the Git structure as a biological landscape.

## Phenotype
Evolutionary visualization of codebase navigation. The TUI visualizes the sequence of Git commits overlaid in a continuous coordinate space (based on the hash), with genetic agents actively moving from one commit to another, consuming their size as energy to sustain their ChimeraVM brains.
