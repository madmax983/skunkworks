# Chimera Hologram 🧬✨

> "Spectral Genetic Logic"

Chimera Hologram is an experimental hybrid crossing `chimera-lang` with `hologram-text`.

It visualizes the execution of genetic logic agents (ChimeraVM) within a 16x16 grid, while simultaneously transforming that 2D spatial memory grid into the frequency domain via Fast Fourier Transform (FFT).

## 🔮 Concept

*   **Parent A**: `chimera-lang` (Grid-based genetic execution, Prologue runes)
*   **Parent B**: `hologram-text` (FFT-based holographic rendering)
*   **Phenotype**: As genetic agents traverse the grid and execute logic gates, their spatial footprint and metabolic state are mapped as optical interference patterns in real-time.

## 🚀 Running

Run the interactive TUI:
```bash
cargo run -p chimera-hologram
```

## 🎮 Controls
* **Space**: Step the VM simulation
* **P**: Play/Pause automatic stepping
* **ESC / Q**: Quit
