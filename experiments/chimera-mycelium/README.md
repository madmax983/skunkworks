# Chimera Mycelium 🍄🧬

**The Splice Surgeon's Latest Hybrid**

A fusion of genetic programming (`chimera-lang`) and chaotic dynamics (`chaotic-mycelium`).

## Concept

Agents (Hyphae) traverse a chaotic landscape generated by the Lyapunov Fractal of the Logistic Map.
Instead of random walking, each agent carries a unique genome (Chimera DNA) that determines its behavior.

- **Input**: The agent senses the local "Chaos Cost" (Lyapunov exponent).
- **Processing**: The ChimeraVM executes the agent's genetic code.
- **Output**: The agent decides to:
    - **Move**: Grow in a specific direction.
    - **Branch**: Spawn a child with mutated DNA.
    - **Die**: Run out of energy.

## Emergent Behavior

Agents evolve to navigate the "stable" regions of the map (low chaos cost) to conserve energy.
Successful navigation strategies (genetic programs) propagate through branching.
