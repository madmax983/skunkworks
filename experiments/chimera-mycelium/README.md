# Chimera Mycelium 🍄🧬

A hybrid experiment combining `chimera-lang` (Genetic Programming) and `social-spores` (Particle Simulation).

## Concept

Nodes in the simulation are fungal colonies running `ChimeraVM` instances. They release "Spores" which are data packets carrying genetic material (DNA).

- **Horizontal Gene Transfer**: When a spore hits another node, it splices its DNA into the host.
- **Genetic Vigor**: Nodes that execute efficient code (gaining energy) grow larger and release more spores.
- **Mycelial Network**: The wind carries the genetic information, creating a distributed evolutionary network.

## Lineage

- **Parent A**: `experiments/chimera-lang` - Provides the `ChimeraVM`, `OpCode` genetics, and mutation logic.
- **Parent B**: `experiments/social-spores` (concept) - Provides the spatial simulation, wind field, and particle interactions.

## Controls

- **Left Click**: Spawn a new random fungal colony.
- **R**: Reset the simulation.
