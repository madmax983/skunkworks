# 🌌 Chimera Stardust

**"The Code is in the Stars."**

A hybrid experiment splicing **Chimera Lang** (Evolutionary Virtual Machine) with **Stardust Compiler** (Nebula Steganography).

## 🧬 Lineage

*   **Parent A**: `experiments/chimera-lang` (The Agent)
    *   *Traits*: Genetic execution, metabolic cycles, virtual machine architecture.
*   **Parent B**: `experiments/stardust-compiler` (The Environment)
    *   *Traits*: Procedural nebula generation, steganographic data encoding (LSB).

## 🔬 The Experiment

In `chimera-stardust`, **ChimeraVM** agents inhabit a procedurally generated nebula.

1.  **Sensing**: Agents read the pixel color at their location (RGB) into their memory grid (`[8][8]..[8][10]`).
2.  **Thinking**: The VM executes its DNA, processing the visual data.
3.  **Acting**: The VM outputs movement vectors (`[0][0]`, `[0][1]`) and color modifications (`[1][0]`, `[1][1]`, `[1][2]`).
4.  **Emergence**: Agents "paint" the nebula as they traverse it, leaving trails of modified pixels. This modification acts as **Stigmergy**—changing the environment for other agents.

## 🚀 Run

```bash
cargo run -p chimera-stardust
```

## 🧪 Observations

*   Agents act as "living noise", scrambling the steganographic potential of the image.
*   The nebula evolves from a static image into a dynamic, glitch-art ecosystem.
