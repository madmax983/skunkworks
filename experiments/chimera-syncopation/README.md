# Chimera Syncopation 🧬🥁

> "The lock is the beat. The wait is the swing." - The Splice Surgeon

**Chimera Syncopation** is a hybrid experiment combining `syncopated-threads` and `chimera-lang`.

## The Concept

This experiment replaces the hardcoded loops of `syncopated-threads` with **living ChimeraVM organisms**.
Each thread runs a genetic program (DNA) that determines its rhythm.

- **Instruments**: Global `Mutex` locks (Kick, Snare, Hat).
- **Musicians**: Independent threads running `ChimeraVM`.
- **DNA**: The code that drives the rhythm. Contains instructions like `Push("PLAY:0:50")` and `Print`.

## Algo-Rhythmic Evolution

The rhythm is not fixed. It is an emergent property of:
1.  **The Code**: The sequence of instructions in the DNA.
2.  **The System**: Thread contention for shared instruments (Mutexes).
3.  **The Jitter**: OS scheduling and VM execution overhead.

## Visuals

The TUI visualizes the state of each musician:
- **Blue**: Sleeping (Resting between notes).
- **Red**: Waiting (Trying to acquire a lock - Syncopation/Tension).
- **Green**: Playing (Holding the lock - Sounding).

## Usage

```bash
cargo run -p chimera-syncopation
```

- Watch the rhythm in the terminal.
- Press `q` to quit.
- Listen to `chimera_syncopation.wav` generated in the project root.
