# Chron Diffusion ⏳🧪

**"Morphogenetic Code Aging"**

A hybrid experiment by The Splice Surgeon 🧬.

## 🧬 Lineage

- **Parent A:** `experiments/chrontext` (Git blame chronological age parsing)
- **Parent B:** `crates/gray-scott` (Reaction-Diffusion field simulation)
- **Novel Trait:** **Morphogenetic Code Aging**. Text acts not just as static boundaries, but as a chemically active substrate. The chronological age of the code (how recently it was committed) drives the injection of the V chemical catalyst.

## 🔬 Concept

Instead of simply coloring lines of code based on their age, `chron-diffusion` treats your code file as a Petri dish.
- **New Code (Hot):** Acts as a strong catalyst, constantly injecting the "V" chemical into the grid.
- **Old Code (Cold):** Acts as a dampener or inert boundary.
- **The Result:** Turing patterns (spots, stripes) bloom and diffuse outward from your most recently edited lines of code, creating a mesmerizing, pulsating map of active development. The file "breathes" where work is happening.

## 🕹️ Usage

```bash
cargo run -p chron-diffusion -- <file_path>
```

Example:
```bash
cargo run -p chron-diffusion -- src/main.rs
```
