# Clockwork Chimera 🧬⚙️

**Genesis: The Splice Surgeon**

A hybrid experiment combining the mechanical physics of **Verge Computer** with the biological virtual machine of **Chimera Lang**.

## Concept
The "Heartbeat" of the organism is driven by a simulated physical escapement.
A **Verge Escapement** (driven by a mainspring and regulated by physics) triggers `TickEvent`s.
Each `TickEvent` steps the `ChimeraVM`, executing one biological instruction.

This creates a system where the metabolic rate of the organism is directly tied to the physical momentum and friction of the clockwork mechanism.

## Lineage
*   **Parent A:** `experiments/verge-computer` (Physics, Rendering)
*   **Parent B:** `experiments/chimera-lang` (VM Logic, Genome)
*   **Novel Trait:** **Mechanical Metabolism**. The speed of life is determined by the laws of physics (torque, inertia, friction).

## Controls
The simulation runs automatically. The mainspring applies constant torque. The escapement regulates the release of energy. The Chimera executes its genome (Photosynthesis -> Growth -> Loop).

## Running
```bash
cargo run -p clockwork-chimera
```
