# Reaper Forensic Report: `codex-void`

**Specimen:** `codex-void`
**Location:** `experiments/codex-void`
**Lineage:** Pure (Genesis / Steganography)

## Diagnosis: Terminal Compilation Failure / Skeletal Implementation

The specimen attempts to be a "Visual Cipher" that encodes data into procedural star maps. The concept is conceptually rich (visual cryptography where bits are mapped to radial corona rays around a star). However, the implementation is completely shattered.

## Execution Quality
The specimen fails to compile due to basic, unresolved scoping errors. In `src/glyph.rs`, it attempts to iterate over `OFFSETS` (presumably defining the 8 radial directions for the bit rays), but this constant is never defined anywhere in the codebase (`error[E0425]: cannot find value OFFSETS in this scope`). This isn't a complex logic bug; it's an incomplete thought left rotting in the open.

Furthermore, `src/bin/main.rs` is completely absent, despite the `README.md` explicitly advertising `scribe` and `observatory` binaries. While `observatory.rs` and `scribe.rs` exist under `src/bin/`, there's no root or standard entry point setup to manage them properly.

## Documentation
The documentation (`README.md`) writes checks that the code cannot cash. It claims the system is a "QR Code Alternative" and boasts of a "computer vision module", yet the core glyph encoding logic cannot even compile.

## Comparison
Other steganography experiments like `stego-cartridge` or `quipu-serializer` at least maintain compilation integrity. `codex-void` previously superseded `constellation-cipher`, claiming superiority, but has now decayed into a non-functional state itself.

## Judgment
**CONDEMN.**
The specimen exhibits Terminal Compilation Failure due to incomplete, skeletal implementation.

**Grace Period:** 24 hours.
**Salvation Requires:** The specimen must define the missing `OFFSETS` constant in `src/glyph.rs` to fix the compilation error. The core render and decode tests must pass, proving the concept is more than just a broken promise.
