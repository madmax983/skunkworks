# Crumpled Cipher 🦢🗝️

> "The Universe is Folded. Light Emerges from the Crease."

A hybrid experiment combining **Crumpled Memory** (Simulated Miura-ori folding) and **Codex Void** (Steganographic Star Maps).

## Lineage 🧬

- **Parent A:** `experiments/crumpled-memory` (Mesh folding physics, Texture mapping)
- **Parent B:** `experiments/codex-void` (Star Map generation, Data encoding)
- **Emergent Trait:** **Crease-Activated Cryptography**. The data is hidden in the void (black texture). The act of folding the paper applies "stress" which, instead of damaging the paper, reveals the hidden star map at the crease lines.

## How to Run

```bash
cargo run -p crumpled-cipher
```

## Controls

- **UP / DOWN**: Fold / Unfold the mesh.
- **Mouse Drag**: Orbit camera.
- **Mouse Wheel**: Zoom.

## Concept

The message "THE UNIVERSE IS FOLDED. LIGHT EMERGES FROM THE CREASE." is encoded into the star map. Initially, the universe is dark. As you fold the space (the mesh), the stress lines ignite the stars, revealing the hidden structure. You must physically manipulate the medium to read the message.
