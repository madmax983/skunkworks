# Ferrous Chimera 🧬🧲

**Lineage:** `ferrous-graph` × `chimera-lang`

A hybrid experiment combining the magnetic physics of `ferrous-graph` with the genetic execution of `chimera-lang`.

## Concept
Agents are powered by a Chimera Virtual Machine. Their "Brain" (DNA) dictates their movement and interaction with the environment.
The environment is a "Magnetic Platter" where agents leave trails (Stigmergy).

- **Sense:** Agents read the local magnetic field intensity into their VM stack.
- **Think:** The VM executes genetic code (DNA).
- **Act:** The VM outputs force vectors (to move) and magnetic emissions (to write to the world).
- **Decay:** The world forgets over time (Magnetic Decay).

## Controls
- `Q`: Quit
- `Arrow Keys`: Pan
- `+/-`: Zoom
- `R`: Reset view

## Technical Details
- **Physics**: Newtonian mechanics from `ferrous-graph`.
- **VM**: ChimeraVM from `chimera-lang` (Path dependency).
- **Rendering**: TUI via `ratatui`.
