# Ferrous Lattice

A hybrid biological and physical visualization engine crossing `miller-lattice` with `ferrous-core`.

## Lineage

* **miller-lattice:** Provides the rigid, crystalline 3D hierarchical structure mapping of a codebase. Nodes represent files and directories built deterministically from the root path.
* **ferrous-core:** Provides the continuous 2D magnetic fluid substrate.

## Novel Trait

**Magnetic Codebase Architecture.** We take the rigid, discrete lattice of the codebase and project it down onto a continuous 2D magnetic fluid plane.

Directories act as positive magnetic poles (emitting a blue aura), while files act as negative magnetic poles (emitting a red aura). As the structural hierarchy of the codebase changes, the nodes naturally pulse and emit localized magnetic fields. The static crystal hierarchy translates into a breathing, swirling fluid dynamic.
