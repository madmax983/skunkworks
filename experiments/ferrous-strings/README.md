# Ferrous Strings 🎻🧲

**Lineage:** `genetic-luthier` (Evolutionary Acoustics) × `ferrous-fluid` (Magnetic Flow).

## Concept
A set of vibrating strings that generate magnetic fields. A swarm of particles flows through this magnetic landscape. The particles are attracted to areas of high magnetic flux.

The system is a closed loop:
1. **Strings Vibrate:** Physical vibration (plucked by mouse) generates magnetic waves on the `Platter`.
2. **Field Guides Matter:** The `Platter`'s magnetic gradients push/pull the swarm of `Particles`.
3. **Matter Selects Genes:** Strings that attract more particles (via their magnetic "song") are considered more fit.
4. **Genes Evolve Strings:** High-fitness strings pass their traits (Frequency, Tension, Decay) to the next generation with mutation.

## Controls
- **Mouse:** Swipe across strings to pluck them.
- **Audio:** Enabled if `cpal` is present (default).

## Emergent Behavior
- Strings that resonate at frequencies that create stable magnetic wells tend to gather more particles.
- "Chord" patterns emerge where multiple strings vibrate in harmony to trap particles between them.
- Chaos ensues when high-energy plucks scatter the swarm.
