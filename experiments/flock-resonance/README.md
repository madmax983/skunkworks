# Flock Resonance 🕊️🔊

A hybrid experiment combining the `flocking` algorithm with the `resonance-audio` wave simulation.

## Lineage

- **Parent A (flocking)**: Provides the boid swarm simulation, including separation, alignment, and cohesion physics.
- **Parent B (resonance-audio)**: Provides the 2D Finite Difference Time Domain (FDTD) wave grid.

## Novel Trait

The continuous physical positions of the boid swarm act as dynamic acoustic oscillators on a 2D FDTD wave grid. As the swarm navigates space, they inject tone frequencies directly into the field, effectively turning flocking dynamics into continuous acoustic chords and interference patterns.
