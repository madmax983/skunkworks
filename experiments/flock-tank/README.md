# Ripple Tank

A 2D physical modeling synthesis experiment.

This experiment simulates the 2D wave equation on a grid, allowing you to visualize and interact with sound waves in real-time. It uses a Finite Difference Time Domain (FDTD) solver to compute pressure propagation, reflection, and interference.

## Features

- **Real-time Wave Simulation**: See the waves propagate, bounce off walls, and interfere.
- **Physical Modeling Synthesis**: The sound you hear is directly generated by sampling the pressure at a "microphone" point in the grid.
- **Interactive**:
    - **Left Click**: Pluck the water surface (inject energy).
    - **Right Click**: Draw walls (reflective boundaries).
    - **Middle Click**: Move the microphone (listener).
    - **Space**: Clear all waves (silence).
    - **C**: Clear all walls.

## Tech Stack

- **Physics**: `resonance-audio` (FDTD solver).
- **Audio**: `cpal` (real-time audio stream).
- **Visuals**: `macroquad` (2D rendering).

## Usage

Run the experiment with audio enabled (requires ALSA on Linux):

```bash
cargo run -p ripple-tank --features audio
```

If you don't have audio libraries installed, you can run in visual-only mode:

```bash
cargo run -p ripple-tank
```

## The Science

The simulation solves the discrete 2D wave equation:

$$ u_{t+1} = 2u_t - u_{t-1} + c^2 \nabla^2 u_t $$

Where $u$ is the wave height (pressure), and $\nabla^2$ is the Laplacian operator (sum of neighbors - center). This creates a physically accurate model of wave propagation in a medium.
