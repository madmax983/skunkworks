## 🔬 Experiment Analysis

This experiment combines flocking behavior with pulse-coupled oscillator synchronization, parameterized by git commit history.

- **Parent A**: `experiments/git-harmonograph` (Git parsing to metadata)

### Concept
What if boids were born from code commits?
**Git Flock** creates a luminous boid for each git commit. The boid's genetic traits (speed, sight, coupling strength, phase, color) are directly parameterized by the entropy of the commit hash and author's name.

### Lineage & Genetics
- **Allele A (DNA Source)**: Commit hashing and parsing from `git-harmonograph`.
- **Allele B (Motion/Time)**: Flocking physics and Kuramoto pulse-coupled synchronization from `luminous-flock`.
- **Emergent Trait**: Waves of light that propagate through moving clusters representing codebase activity.
