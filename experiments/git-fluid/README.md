# 🧬 Git Fluid

A TUI visualization crossing the Git commit history of `git-harmonograph` with the magnetic fluid simulation of `ferrous-fluid`.

## 🧬 Lineage

- **Parent A:** `experiments/git-harmonograph` (Git metadata parsing and commit stepping)
- **Parent B:** `experiments/ferrous-fluid` (Ferrous fluid particle physics and grid-based density pressure)
- **Novel Trait:** Codebase history translating into magnetic fluid structures. Each commit acts as a set of magnetic poles mapped from the SHA-1 hash, pushing and pulling fluid particles around, providing a magnetic fingerprint of code evolution.

## 🔬 Phenotype

By mapping the 40-character SHA-1 hashes of Git commits to the `xyz` position, strength, and polarity of 5 different magnets, the visualization provides a dynamic, physical fingerprint of each code change. As you step through history, the magnetic particles form organic, swirling, or chaotic patterns driven by the entropy of the repository.

## 🕹️ Controls

- **Left / Right (or H/L)**: Navigate through commit history.
- **Q / Esc**: Quit.
