### Concept
Rather than using commits to drive pendulums, **Git Hologram** uses commit hashes to define the "resonant frequency" of a holographic particle swarm.

1. The first byte of each commit hash is mapped to a `resonance_dist` parameter.
2. The particle positions (spatial domain) are transformed into the frequency domain (via 2D FFT).
3. A Gaussian band-pass filter, centered at `resonance_dist`, amplifies specific frequencies in the spectrum.
4. The filtered spectrum is transformed back (IFFT) into a "Ghost Potential Field".
5. Particles are pushed away from the high-energy regions of this potential.

As you navigate through Git history, the swarm reshapes itself into different resonant patterns dictated by the entropy of the codebase.
