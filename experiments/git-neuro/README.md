# Git Neuro 🧬

## The Hybrid Concept

This experiment crossbreeds the discrete, chronological commit history of a repository (`git-associates`) with the biological, chaotic firings of a Spiking Neural Network (`neuro-sim`).

## Novel Trait
We map discrete repository modifications directly to neural injection currents. The codebase history becomes the physical environment that a neural network attempts to "digest". Commits with heavy line modifications act as massive electrical jolts to specific neural pathways, simulating the "cognitive load" or "stress" of a given historical code change.

## Predicted Phenotype
An emergent simulation where the repository history becomes a sequence of electrical storms in a synthetic brain. Spikes propagate through the hidden synaptic connections, echoing the ripple effects of code modifications long after the initial commit has been processed.

## Lineage
- **Parent A (git-associates)**: Provides the discrete chronology of commit hashes and the volume of diff changes over time.
- **Parent B (neuro-sim)**: Provides the biological Izhikevich neural modeling and synapse-delayed spike propagation.
