# git-platter

A biological hybrid crossing `git-associates` and `platter`.

## Concept
Git History Heatmap.

## Novel Trait
Projecting discrete file modifications across a codebase's history into a continuous 2D scalar field. Codebase modifications dynamically heat and cool the field.

## Predicted Phenotype
An evolving heatmap showing areas of high codebase churn.

## Usage
```bash
cargo run -p git-platter
```
