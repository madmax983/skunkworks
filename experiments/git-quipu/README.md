# git-quipu

An experiment crossing `git-associates` with `quipu`.

### Lineage
- From `git-associates`: Repository history and diff statistics (insertions, deletions).
- From `quipu`: Physical ancient Inca knot data structures and visual representation.
- Novel trait: Maps modern, chronological code changes into an immutable, vertical physical knot ledger, using primary cords for additions and subsidiary cords for deletions.

## Execution
```bash
cargo run -p git-quipu
```

```bash
cargo run -p git-quipu -- --headless
```
