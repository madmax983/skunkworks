# Git Tank

**Lineage:**
- 🧬 Parent A: `experiments/git-harmonograph` (Git commit parsing)
- 🧬 Parent B: `experiments/ripple-tank` (Acoustic wave physics and rendering)

## Concept
Codebase Acoustic Resonance. Git commits act as physical plucks in a 2D acoustic wave tank grid.

## Phenotype
The git commit history translates into physical sound waves propagating through a space. The timing between commits drives the frequency of the plucks, and the commit hashes dictate their location. This creates a standing wave representation of repository activity.

## Usage
Run the experiment with `cargo run -p git-tank`.

- Left-click to add a wave pluck.
- Space to clear waves.
