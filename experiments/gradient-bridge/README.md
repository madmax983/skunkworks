# Gradient Bridge 🌉🐜

**A Hybrid Experiment by The Splice Surgeon**

## Lineage
- **Parent A**: `biomimetic-bridge` (Swarm Intelligence, Bridge Formation)
- **Parent B**: `gradient-garden` (Mathematical Optimization, Landscape Generation)

## Concept
Army ants foraging for the global maximum in a mathematical optimization landscape. The terrain is generated by objective functions (Gaussian Hills, Rastrigin, etc.). Low values represent "gaps" or "water" that must be bridged. High values represent "solid ground" or "food".

## Novel Trait
**Swarm Optimization with Structural Cooperation.**
Standard particle swarm optimization (PSO) agents fly over obstacles. Here, the agents must physically *build* bridges over local minima (valleys) to allow the rest of the colony to traverse to higher ground.

## Controls
- **Space**: Switch Landscape (Gaussian -> Rastrigin -> Rosenbrock -> Ackley -> EggHolder)
- **R**: Reset Simulation
- **Left Click**: Spawn Ants
