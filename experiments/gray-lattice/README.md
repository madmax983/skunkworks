# gray-lattice

**Lineage:**
- From `miller-lattice`: 3D discrete crystal lattice generation based on the actual repository's hierarchical file structure.
- From `gray-scott`: Continuous 2D chemical reaction-diffusion simulation.

**Concept:**
Code Entropy Morphogenesis.

**Novel Trait:**
This experiment maps the discrete, rigid crystal lattice of the `miller-lattice` codebase structure directly into the continuous chemical substrate of the `gray-scott` grid.
The rigid structural components of the codebase act as active chemical catalysts. Directories act as continuous sources of the 'kill' (V) chemical, establishing hard biological boundaries or "decay zones." In contrast, files act as continuous sources of the 'feed' (U) chemical, acting as growth centers.

**Predicted Phenotype:**
An organic visualization where the uniform Euclidean chemical diffusion of Turing patterns is physically guided, constrained, and warped by the underlying static architecture of the codebase. The resulting visual footprint is a biological map of structural entropy, where dense directory trees create "dead zones" and large flat file clusters foster vibrant morphogenetic growth.
