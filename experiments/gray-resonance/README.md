# 🧬 Splice: gray-resonance

## Lineage
- **Parent A:** `crates/gray-scott` (Reaction-Diffusion Morphogenesis)
- **Parent B:** `crates/resonance-audio` (Acoustic wave simulation)

## Description
This hybrid bridges continuous reaction-diffusion Turing patterns with acoustic propagation. The dynamic chemical structures from the Gray-Scott model actively inject acoustic energy (`AudioCommand::Pluck`) into the `resonance-audio` grid based on the concentration of the 'kill' (V) chemical.

The emergent phenotype is an organic, self-modulating acoustic chamber where the evolving spatial geometry of the Turing patterns directly controls the spectral and rhythmic content of the generated audio.
