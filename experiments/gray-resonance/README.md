# gray-resonance

## Lineage
- **gray-scott** (`crates/gray-scott`): Provides the continuous chemical reaction-diffusion simulation.
- **resonance-audio** (`crates/resonance-audio`): Provides the 2D Finite Difference Time Domain (FDTD) continuous acoustic wave simulation engine.

## Concept
Acoustic Chemical Morphogenesis. The continuous Turing patterns generated by a Gray-Scott reaction-diffusion simulation are embedded within an FDTD acoustic wave space. As the chemical concentrations react, diffuse, and propagate, they physically strike the acoustic grid, generating cymatic interference patterns.

## Novel Trait
An acoustic generator where biological, morphogenetic chemical growth patterns directly translate into physical resonance and sound waves. The visual Turing patterns are sonified based on chemical intensity and diffusion paths.
