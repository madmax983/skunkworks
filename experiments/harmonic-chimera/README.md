# 🧬 Hybrid Experiment: `harmonic-chimera`

> "The best ideas are mongrels." - The Splice Surgeon

## 🔬 Lineage

*   **Parent A**: `experiments/harmonic-engine` (Mechanical Differential Analyzer Simulation)
*   **Parent B**: `experiments/chimera-lang` (Biologically-inspired Esoteric VM)
*   **Hybrid**: `harmonic-chimera` (Mechanical Genetic Programming)

## 🧬 Concept

What if code could build its own body?

`harmonic-chimera` is a simulation where evolving ChimeraVM agents ("Engineers") are tasked with constructing a mechanical computer using Ball-and-Disk Integrators. The agents do not solve the problem directly; instead, they build a physical machine (a network of coupled differential equations) that solves the problem.

The "Genome" is a Chimera program.
The "Phenotype" is a `PhysicsWorld` populated with integrators and gears.
The "Fitness" is the ability of the machine to maintain a stable oscillation (a limit cycle) without exploding or stopping.

## 🧪 Novel Traits

*   **Constructive Physics**: The genetic code is a blueprint for a physical machine. The VM executes to *build* the world, not just live in it.
*   **Mechanical Logic**: The resulting organism is a hybrid of software (DNA) and hardware (Gears).
