# Heap Painter 🎨💾

> "Abstract expressionism generated by memory allocation."

**Heap Painter** is a cross-sensory translation experiment that visualizes the state of a simulated memory allocator as an abstract digital canvas.

## The Concept

This experiment smashes together **Memory Heap Layout** and **Abstract Expressionist Canvas**.
- **The Canvas**: A 2D grid representing the heap memory space.
- **The Paint**: Allocated memory blocks.
- **The Color**: Determined by the "age" (allocation time) and "type" (random seed) of the allocation. Hot/New allocations are white/yellow, cooling into colorful blocks, and eventually settling into cold dark static.
- **The Brush**: A simulation agent that allocates and frees memory according to different patterns (Chaos, Linear, Wave).

## Usage

Run the experiment:
```bash
cargo run --bin heap-painter
```

### Controls

- **SPACE**: Switch Brush Mode (Chaos -> Linear -> Wave -> ...)
- **Q / ESC**: Quit

## Modes

- **Chaos**: Random allocations and frees. Creates a fragmented, noisy texture.
- **Linear**: Sequential allocations and FIFO frees. Creates orderly, shifting bands of color.
- **Wave**: Allocations follow a sine wave pattern in size. Creates rhythmic pulses on the canvas.

## Implementation Details

- **Allocator**: A custom first-fit memory allocator simulation.
- **Visualization**: Built with `ratatui` and `crossterm`.
- **Metrics**: Real-time tracking of heap fragmentation.
