## Controls

- **Arrow Keys:** Adjust the angle of the reconstruction beam (shift the frequency view).
- **Space:** Deploy a random Chemical Firewall to disrupt the swarm.
- **Mouse Click:** Deploy a firewall at an approximate location.
- **C:** Clear all Firewalls.
- **Enter:** Reset viewing angle to the perfect recording angle.
- **Esc / Q:** Quit.
