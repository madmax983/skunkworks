# Holographic Strings

A Moonshot experiment combining **Codebase Sonification** and **Physical Modeling**.

## Concept
Every file in the repository is a vibrating string.
The file size determines the pitch (Karplus-Strong physical model).
The file extension determines the color.
You fly through the "Code Forest" using WASD + Mouse.
Touching a string "plucks" it, generating sound.

## Audio
Currently runs in "Offline Mode" due to environment limitations (no ALSA/Jack).
The session is recorded and saved to `recording.wav` when you exit the app.

## Controls
- **W/A/S/D**: Move
- **Mouse**: Look
- **Space**: Up
- **Shift**: Down
- **Esc**: Release mouse
- **Click**: Grab mouse
