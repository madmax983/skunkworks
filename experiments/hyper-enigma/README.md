# Hyper Enigma 🌌🔐

> "The key is not a number, but a coordinate in 4D space."

A **4D Polyalphabetic Cipher Machine** visualized as a rotating Tesseract.

## Lineage 🧬

*   **Parent A**: `tesseract-ops` (4D Hypercube Visualization, Macroquad Rendering)
*   **Parent B**: `clockwork-cipher` (Physical Cryptographic Machines)

## Concept

This experiment implements a cryptographic machine where the "Rotor" is a 4-dimensional hypercube (Tesseract).

*   The machine has **6 Rotors**, corresponding to the 6 planes of rotation in 4D space:
    *   XY, XZ, YZ (Standard 3D rotations)
    *   XW, YW, ZW (4D rotations involving the W-axis)
*   Each key press advances the rotors by chaotic, irrational steps.
*   The current rotational state of the Tesseract determines the cipher shift.
*   To decrypt a message, one must reproduce the exact sequence of 4D rotations (the "Path" through hyperspace).

## Controls

*   **Typing (A-Z)**: Encrypts the character and rotates the Tesseract.
*   **Arrow Keys**: Rotate the 3D Camera.
*   **W / S**: Zoom In / Out.

## Emergent Traits

*   **Hyper-Rotational Cryptography**: The complexity of the cipher scales with the dimensionality of the rotation space.
*   **Visual Hashing**: The visual state of the Tesseract is a direct representation of the encryption key state.
