# 🧬 hyper-git (Hybrid Experiment)

**Parents:** `crates/hyper-system` × `crates/git-associates`

## Concept: Higher-Dimensional Codebase History
This hybrid maps the temporal evolution of a Git repository directly into hyper-dimensional space. By converting codebase metadata into geometric variables, it visualizes the history of the repository as 4D torque.

## Lineage Documentation
- **From `git-associates`:** Extraction of chronological commit history, including commit hashes and message lengths. This acts as the temporal data source driving the visualization.
- **From `hyper-system`:** 4D vector mathematics (`Vec4`). These structures provide the mathematical foundation for representing rotation across planes beyond standard 3D space.

## Emergent Phenotype
We witness a thermodynamic visualization of a 4D structure where the rate of change and complexity of codebase evolution directly map to geometric hyper-dimensional torque, allowing developers to "see" the momentum of their commits.
