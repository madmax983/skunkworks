# hyper-market 🧬

**Status**: Experimental
**Lineage**: `hyper-system` × `market-sim`

This hybrid crosses the 4D geometric projection of `hyper-system` with the continuous double auction particle physics of `market-sim`.

## Phenotype
**4D Financial Liquidity:** Trade events and liquidity shocks in the 2D market simulation inject torque directly into the hyper-dimensional coordinate space. As trades execute, the 4D geometric projection spins faster, visualizing market activity as impossible geometric rotation intersecting with our 3D space.

## Execution

```bash
cargo run -p hyper-market
```
