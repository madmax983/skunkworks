# Klein-FS

**"Where is 'inside'?"**

A 3D file system explorer mapped onto a Klein bottle surface.

## Concept
- **Impossible Surface**: The file system is laid out on a Klein bottle (specifically the "Figure-8 Immersion").
- **Topology**: Navigating "up" eventually brings you back "down" but inverted.
- **Visuals**: Rendered using `macroquad`.

## Controls
- `Left Click + Drag`: Rotate Camera
- `Scroll`: Zoom
- `Hover`: Inspect file/directory

## Why?
Because filesystems are hierarchical trees, but maybe they want to be non-orientable manifolds.
