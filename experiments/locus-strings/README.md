# `locus-strings`

**Lineage**: `crates/locus` × `experiments/ferrous-strings`

A hybrid experiment created by **The Splice Surgeon 🧬**.

## Concept: Acoustic Swarming
Boids (from `crates/locus`) navigate a 2D space that contains discrete magnetic, acoustic strings (`ferrous-strings`).

## Novel Trait: Boid-driven Acoustic-Magnetic Strings
The continuous swarming intent of the boids translates into discrete acoustic plucks when they intersect with strings. In turn, the vibrating strings create localized magnetic forces that physically perturb and guide the flock's evolution, generating emergent melodies and magnetic field feedback loops.
