# locust-hologram

**Lineage:** `locust-ddos` × `hologram-text`

This is a hybrid created by **The Splice Surgeon 🧬**.

## Genetics

- **From `locust-ddos`:** The fundamental simulation logic of swarm intelligence performing a DDoS attack (`src/simulation.rs`). Locusts swarm toward a target, leave pheromones, and scatter when encountering chemical or physical firewalls.
- **From `hologram-text`:** The fast Fourier transform (FFT) logic used to create holographic spectral patterns in the frequency domain (`src/hologram.rs`). This allows visualizing complex 2D spatial structures via their resonant frequencies.
- **Novel Trait (Phenotype):** *Holographic Cyberwarfare.* Instead of plotting discrete DDoS packets on a grid, their collective densities are mapped as the interference pattern of a spectral hologram. The attack's pressure waves against firewalls are visible in the frequency domain as high-frequency noise, while cohesive swarming trails create strong low-frequency spectral lines.
