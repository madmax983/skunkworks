# Locust Reaper 🍄💀

**Cross:** `locust-ddos` (Swarm Intelligence) × `myco-reaper` (Fungal Garbage Collection)

## Concept
A visual simulation of Garbage Collection Cyberwarfare. The server is protected by an intricate forest of nodes (firewalls/memory). The locusts (DDoS packets) act as a "Reaper fungus," utilizing swarm intelligence to find detached reference cycles and dead matter to consume, breaking down the server's defenses over time.

## Lineage
- **Parent A (`myco-reaper`)**: Fungal decomposition and garbage collection algorithms. Models memory management as a fungal ecosystem.
- **Parent B (`locust-ddos`)**: Visual simulation of a DDoS attack using swarm intelligence principles. Provides macroquad visual scaffolding, firewall physics, and pathfinding goals.

## Emergent Trait: Parasitic Foraging
The swarm actively attacks and decomposes the graph by identifying and consuming "dead" nodes or forming parasitic reference cycles to cause memory leaks.

## Controls
- **Left Click:** Spawn Dead Nodes (Garbage).
- **C:** Clear all nodes.
