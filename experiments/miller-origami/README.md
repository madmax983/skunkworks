# Miller-Origami 🧬

A hybrid experiment spawned by **The Splice Surgeon 🧬**.

## Concept: Codebase Soft-Body Morphogenesis
A breathing, physical soft-body representation of the repository's directory tree. Combines the discrete 3D crystal lattice generated by `miller-lattice` with the continuous folding mesh of `origami`.

The structural dependencies and file pathways act as continuous, breathing tissue that expands and contracts, translating a rigid codebase layout into an organic, breathing organism based on the Miura-ori fold.

## Lineage
* **Parent A (`miller-lattice`)**: Contributes the discrete filesystem crawling and Crystal data structure generation.
* **Parent B (`origami`)**: Contributes the continuous `MiuraParams` soft-body spatial mapping and time-varying extension logic.
* **Emergent Phenotype**: The discrete rigid bonds between filesystem nodes are mapped dynamically to vertices on a continuous Miura origami grid, causing the entire lattice to physically fold, contract, and breathe over time.

## Execution
Run visually using `cargo run -p miller-origami`.
Supports standard ecosystem `--headless` bypass logic.
