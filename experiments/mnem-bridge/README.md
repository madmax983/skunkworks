# Mnemonic Bridge 🌉🧠

A hybrid experiment combining swarm intelligence with memory decay.

## Parents
- **Parent A:** `experiments/mnem-rot` (Mnemonic Decay)
- **Parent B:** `experiments/biomimetic-bridge` (Army Ant Structures)

## Concept
Ants (agents) traverse a void by forming living bridges. Each ant carries a "memory" payload.
As an ant becomes part of the bridge structure, its health decays, and its memory becomes corrupted (text glitching).
If an ant's health reaches zero, the bridge segment collapses, representing the loss of structural and semantic integrity due to entropy.

## Controls
- **Left Click:** Dig Gap (create void)
- **Right Click:** Fill Gap (create solid ground)
- **Space:** Spawn more ants
- **R:** Reset simulation
- **Hover:** View the memory payload of a bridge node (ant)
