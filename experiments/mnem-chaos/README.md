# Mnemonic Chaos (`mnem-chaos`)

A visual experiment simulating the decay of a codebase network under the chaotic influence of a double pendulum.

## 🧬 Lineage

This hybrid was created by crossing the following experiments:

- **Parent A:** `experiments/mnem-rot` (Mnemonic Rot)
  - *Inherited Traits:* Codebase graph rendering, file node loading, and entropy visualization logic (TUI with ratatui).
- **Parent B:** `experiments/chaos-pendulum` (Chaos Pendulum)
  - *Inherited Traits:* Double pendulum mathematics and physics simulation logic.

## 🌟 Emergent Phenotype

**Chaotic Decay Mapping:** Instead of passive decay or intentional agent foraging (as seen in `mnem-rot`), the codebase's health is subjected to a pure mathematical chaotic attractor. The double pendulum bob acts as an extreme source of entropy, violently aging and decaying any codebase nodes it passes over. The health of the codebase becomes a history map of the pendulum's chaotic orbit, creating a dynamic tug-of-war between structural resilience and mathematical chaos.
