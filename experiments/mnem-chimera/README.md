# Mnem-Chimera: Entomological Code Rot

## Concept
A hybrid splice of `mnem-rot` and `chimera-lang`.
Entomological Code Rot: `ChimeraVM` agents navigate the continuous codebase graph generated by `mnem-rot`. They execute DNA to forage for high-entropy (rotting) nodes and "repair" them by spending energy.

## Lineage
- **From mnem-rot:** The continuous file system graph. Nodes represent files and edge strings connect related nodes. Entropy is derived from file size/complexity and drives visual decay.
- **From chimera-lang:** The agents. They contain `ChimeraVM` brains, which read the local node's entropy and run genetic instructions to decide whether to migrate or forage (heal the node).

## Predicted Phenotype
Swarms of cybernetic agents adapting their pathfinding to locate areas of maximum code decay, acting as an active "immune system" for the codebase.
