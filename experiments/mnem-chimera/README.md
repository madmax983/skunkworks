# Mnemonic Chimera (`mnem-chimera`)

**Lineage:** `mnem-rot` × `chimera-lang`

## Concept: Genetic Code Rot

Mnemonic Chimera creates a bio-digital ecosystem where artificial genetic organisms (`ChimeraVM`) inhabit the structural memory graph of a codebase. The repository is visualized as a network of nodes (files) connected by edges (dependencies/imports), with each node possessing a continuously decaying "health" value representing entropy/rot.

Instead of moving across a blank spatial canvas, the agents traverse the specific, literal architecture of the code. The codebase graph serves as their environment and fitness function.

## Lineage

*   **From `mnem-rot`:** The visual graph construction mapping source files to nodes, dependency parsing to edges, and the active decay/entropy simulation over time.
*   **From `chimera-lang`:** The genetic virtual machine execution loop, opcodes, and stack-based biological simulation rules.
*   **Novel Trait - Entropy-Driven Evolution:** Instead of abstract geometry, the agents sense the *entropy* (health) of actual source code files they reside on. Healthy files nourish them, while decaying files drain their energy. The agents evolved to navigate between connected modules based on their genetic instructions, effectively treating the repository graph as a survival landscape. As they interact, they act as "repair drones", increasing the health of the nodes they traverse, forming a symbiotic loop between codebase structure and artificial genetics.
