# Mnemonic Hologram 🧬🔮

> "The spectral signature of architectural decay."

**Mnemonic Hologram** is a TUI hybrid experiment combining the codebase structural entropy mapping of `mnem-rot` with the spectral FFT-based optical interference rendering of `hologram-text`.

## 🧬 Lineage

- **Parent A:** `experiments/mnem-rot`
  - *Alleles Inherited:* Codebase parsing via `walkdir` and `regex`, mapping source files as nodes and dependency imports as edges. Spring-force graph layout logic. Health decay tracking (entropy).
- **Parent B:** `experiments/hologram-text`
  - *Alleles Inherited:* Holographic interference simulation via 2D Fast Fourier Transform (FFT). Spatial-to-frequency domain mapping and inverse-FFT reconstruction.

## 🔬 Phenotype

**Spectral Structural Entropy:** Instead of observing codebase rot visually directly as text corruption, this cross maps the 2D spatial arrangement of the dependency graph into a continuous density field, which is then transformed into an optical interference pattern (a hologram).

As the codebase "rots" (entropy increases), nodes lose their structural cohesion, start to jitter chaotically, and their density profiles spread out into noise. When viewed in the frequency domain (the hologram), the sharp, distinct resonant frequencies of a well-organized codebase blur and decompose into a high-frequency turbulent fog.

We are visually observing the *acoustic and spectral decay* of technical debt.

## 🎮 Controls

- **Arrow Keys:** Adjust the angle of the reconstruction beam.
- **Enter:** Reset angle to the perfect recording angle (clear image).
- **Space:** Increase entropy (accelerate rot/jitter).
- **`h`:** Heal the codebase (reduce entropy, restore node health).
- **`q` or `Esc`:** Quit.

## 📦 Usage

Run from the root of a workspace:

```bash
cargo run -p mnem-hologram
```
