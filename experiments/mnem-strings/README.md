# mnem-strings

Acoustic Manifestation of Code Decay.

A hybrid of `mnem-rot` and `ferrous-strings` where decaying nodes in a codebase graph act as objects that physically strike and pluck acoustic strings as their entropy increases.

## Controls
- **Right Click & Drag**: Pan camera
- **Scroll**: Zoom in/out
- **Left Click on Node**: Restore health/maintain code
- **Left Click on background**: Drop magnetic poles to interact with nodes

## Phenotype
Nodes dynamically fall out of the graph layout due to simulated entropy (decay). As they fall, they interact with physical string simulations, creating an acoustic representation of code rot. The strings themselves also decay when plucked by rotting code.
