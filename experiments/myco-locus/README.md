# Topological Mycelial Transit

**Lineage:**
- From `myco-transit`: Slime mold (Physarum polycephalum) pathfinding and pheromone-guided swarming agents.
- From `locus`: Topological mappings (Torus, Klein Bottle, Cylinder) for non-Euclidean boundary wrapping.

**Concept:**
Topological Mycelial Foraging. The slime mold agents navigate a continuous 2D space governed by `locus` topological constraints instead of simple Cartesian plane bounds.

**Novel Trait:**
Pheromone routes successfully wrap seamlessly across topological boundaries (e.g., across the north and south poles of a Sphere, or twisting across a Klein Bottle). Agents sense pheromone trails that loop across boundaries.

**Predicted Phenotype:**
An organic network of fungal highways demonstrating shortest-path routing over continuous non-Euclidean boundary layers, producing seamless wrap-around structural clusters.
