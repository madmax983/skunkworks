# Myco-Stego: Bio-Decryption

**Parents:** `experiments/myco-diffusion` (Physarum) × `experiments/stego-cartridge` (Steganography)

## Concept

*Myco-Stego* is a TUI-based simulation where Physarum Polycephalum (slime mold) agents "forage" for hidden data.

The environment contains a hidden "Food Layer" generated by procedurally embedding a pattern (a circle or cross) into the grid, mimicking steganographic data (like LSBs in an image).

The agents are attracted to both their own pheromone trails (traditional Physarum behavior) AND the hidden data signal.

**Novel Trait: Bio-Decryption.** The organism's growth pattern reveals the hidden message. The network structure *is* the decoded data.

## Implementation

*   **Grid:** A pheromone grid that diffuses and decays.
*   **Hidden Layer:** A boolean grid representing the hidden "food" pattern.
*   **Agents:** 2000 agents that move, sense, and deposit pheromones.
*   **TUI:** Rendered using `ratatui` Canvas widget with Braille-like point density.

## Controls

*   `q`: Quit the simulation.

## Lineage

*   From `myco-diffusion`: The Physarum movement and sensing logic (Agent, Grid, Diffusion).
*   From `stego-cartridge`: The concept of "Hidden Data" as a primary attractor for the system.
