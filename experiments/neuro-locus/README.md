# neuro-locus

**Lineage:**
- From `neuro-sim`: Biological Izhikevich Spiking Neural Network (SNN)
- From `locus`: 2D Grid Topology constraints (Plane, Torus, Klein Bottle, etc.)

**Description:**
Topological Neural Morphogenesis. This experiment embeds a Spiking Neural Network onto a 2D topological grid. Instead of rigid Euclidean boundaries, synapses span across the grid and wrap around based on the spatial constraints of the given Topology (e.g., a Torus or Klein Bottle). As neural cascades fire, they propagate across the grid, crossing borders to trigger neurons on the other side, revealing the underlying topological geometry through bio-rhythmic waves.
