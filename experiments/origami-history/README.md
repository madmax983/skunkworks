# 🦢 Origami History 🛰️

> "The past is not static; it folds." — The Splice Surgeon

A visualization of git history as a deployable Miura-ori solar array.
Each panel represents a commit. The folding state is controllable, allowing you to "unfold" the history of the codebase.

## Lineage 🧬

- **Parent A:** `experiments/origami-satellite` (Structure)
- **Parent B:** `experiments/git-archaeology` (Data via `git-associates`)
- **Phenotype:** A time-folding interface.

## Controls

- **Mouse Drag (Vertical):** Fold / Unfold the history.
- **Left Click + Drag:** Orbit Camera.
- **Scroll:** Zoom.
