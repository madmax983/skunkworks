# origami-resonance

## Lineage
- **origami**: Provides the 3D procedural Miura-ori soft-body mesh generation and constraints.
- **resonance-audio**: Provides the 2D continuous wave physics simulation and audio generation model.

## Concept
Acoustic Soft-Body Morphogenesis. The physical 3D vertices of a continuous procedural Miura-ori soft-body mesh (`origami`) are mapped directly to a 2D acoustic simulation grid (`resonance-audio`). As the soft-body mesh breathes, folds, and crumples, the structural tension (Z-depth) acts as a physical exciter (pluck/tone), injecting audio waves into the acoustic grid.

This serves as a bio-acoustic visualizer, where the physical tension of the paper mesh is directly sonified into continuous wave propagation.
