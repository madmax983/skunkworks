# platter-market

## Thermodynamic Market Liquidity

This experiment demonstrates a thermodynamic approach to market liquidity, bridging the continuous thermodynamic scalar field of `platter` with the discrete order book dynamics of `market-sim`.

## Lineage
- **Parent A:** `platter` (Topological Scalar Field Morphogenesis).
- **Parent B:** `market-sim` (Continuous Double Auction dynamics).
- **Novel Trait:** The discrete financial order book grid successfully maps into the continuous scalar heat field. Bids and asks generate low heat, while trades burst with massive kinetic thermal energy at their precise coordinate intersections within the order book grid.

## Usage
Run the visualizer:
```bash
cargo run -p platter-market
```

Run headless CI simulation bypass:
```bash
cargo run -p platter-market -- --headless
```

## Bidirectional Emergence
The spatial mapping ensures that localized areas of high trading activity directly correspond to hotspots in the scalar field, creating a bidirectional feedback loop between structural market orders and emergent thermal diffusion.
