# Poincare Lattice 🧬

A hybrid biological and physical visualization engine crossing `miller-lattice` with `poincare-disk`.

## Lineage

* **miller-lattice:** Provides the rigid, crystalline 3D hierarchical structure mapping of a codebase. Nodes represent files and directories built deterministically from the root path.
* **poincare-disk:** Provides a continuous 2D non-Euclidean space (hyperbolic geometry).

## Novel Trait

**Hyperbolic Codebase Morphogenesis.** We project the discrete, hierarchical 3D directory structure from `miller-lattice` into the continuous 2D Poincaré disk.

The root of the repository is placed at the Euclidean center. As we traverse the file tree outward, child nodes are mapped progressively closer to the boundary ($|z| \to 1$). Due to the hyperbolic geometry, distance scales exponentially. This means that a sprawling, deeply nested hierarchy compresses incredibly densely at the edges, warping its Euclidean perception while maintaining structural relativity.

## Predicted Phenotype

An organic, relativistic mapping of a codebase. The core architecture remains central and spacious, while deep dependency trees or heavy nested folders compress into dense clusters on the infinite boundary, showcasing non-Euclidean boundary compression.
