# poincare-origami

**Lineage:**
- From `poincare-disk`: Hyperbolic space model and Non-Euclidean geometry
- From `origami`: Procedural Miura-ori soft-body mesh

**Description:**
Hyperbolic Morphogenesis. This experiment projects a 3D Miura-ori mesh into the interior of a 2D Poincaré disk. The hyperbolic geometry constraints physically warp the mesh as the origami folds, acting as an active force parameter for soft body position-based dynamics.
