# quipu-flock

**Concept:** Swarm-Driven Knotted Data Storage

This hybrid experiment crossbreeds the swarm intelligence of `flocking` with the knotted data structure of ancient Inca `quipu`.

## Lineage

* **Parent A:** `crates/flocking` - Provides emergent biological swarm intelligence (boids).
* **Parent B:** `crates/quipu` - Provides the ancient Inca knotted cord storage system.

## Novel Trait

Instead of statically adding data to knots, the boids dynamically act as data weavers. As the swarm navigates the 2D plane, groups of boids that stick together tightly (cohesion) generate continuous data integers that are encoded as new knots into a central quipu cord system. The flocking behavior directly determines the sequence and magnitude of the encoded knots.
