# Quipu Resonance

**Lineage:**
- From `quipu`: Data representation via knots (Cord / Quipu)
- From `resonance-audio`: Acoustic wave simulation in a 2D physical grid

**Novel Trait:**
Acoustic translation of physical knots. The discrete structures of Quipu (the knots) act as physical dampeners and exciters within a continuous 2D acoustic wave tank simulation.
When a "Cord" is dropped into the wave tank, its knots displace water and generate physical sound waves, while also reflecting them based on their position and size. This visualizes and sonifies the data stored within the Quipu.
