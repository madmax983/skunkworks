# Regex Defense

A TUI game where you defend against waves of falling text by typing Regular Expressions.

## How to Play
- **Type** a regex pattern in the input box.
- **Press Enter** to fire.
- Any falling text that **matches** the regex is destroyed.
- **Score** points based on complexity and length.
- **Don't let the text hit the bottom!**

## Controls
- `Enter`: Submit Regex
- `Backspace`: Delete character
- `Esc`: Quit
