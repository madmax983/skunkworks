# Source Rain 🌧️

A Matrix-style code rain visualizer that uses your own source code as the rain.

## Concept
Scans the current directory for `.rs` files and uses the lines of code to generate falling streams of characters. It turns your codebase into a cyberpunk aesthetic experience.

## Controls
| Key | Action |
| --- | --- |
| `q` / `Esc` | Quit |
