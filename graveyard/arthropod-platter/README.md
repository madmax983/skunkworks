# arthropod-platter

**Lineage:**
- From `arthropod`: The interactive, immediate-mode UI component library (buttons) handling user inputs.
- From `platter`: The continuous 2D scalar field data structure managing heat/pheromone accumulation, saturation, and decay.

**Novel Trait:**
The discrete, abstract GUI buttons of `arthropod` directly inject localized physical heat into the continuous scalar field of `platter`. The immediate mode interactions translate instantly into thermodynamic energy that decays over time.

**Predicted Phenotype:**
An interactive thermodynamic playground where abstract UI inputs physically warm up the continuous simulation environment, creating fading visual heatmaps of user interaction history.
