# Chimera Circuit 🧬🔌

**Hybrid of:** `experiments/circuit-sigil` + `experiments/chimera-lang`

A simulation where ChimeraVM agents ("Data Packets") traverse a procedural PCB generated from git history.

## Concept
- **The World**: A Printed Circuit Board (PCB) generated by `circuit-sigil`.
- **The Life**: Agents running `chimera-lang` DNA.
- **The Goal**: Navigate traces, reach pads, consume energy, and evolve.

## Mechanics
- **Sensors**: Agents can read the surface under them via `GRead`.
  - `(0,0)`: Trace Signal (1 = On Trace, 0 = Off Trace).
  - `(0,1)`: Distance to nearest target Pad.
  - `(0,2)`: Angle to nearest target Pad.
- **Actuators**: Agents control movement via `GWrite`.
  - `(15,0)`: Steering (-100 to 100).
  - `(15,1)`: Speed (0 to 5).
- **Metabolism**:
  - Moving off-trace drains energy rapidly.
  - Reaching a Pad recharges energy.

## Controls
- `R`: Regenerate circuit and reset population.

## Lineage
- `src/circuit.rs`: Adapted from `experiments/circuit-sigil`.
- `src/bio.rs`: Agent logic using `chimera-lang` VM.
