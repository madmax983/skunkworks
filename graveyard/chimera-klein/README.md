# Chimera Klein

**Parents**: `experiments/klein-life` + `experiments/chimera-lang`

## Concept
ChimeraVM agents inhabiting a non-orientable surface (Klein Bottle).

## Novel Trait
**Chiral Mutation**. When an agent crosses the topological twist of the Klein bottle, its "Body" (handedness) and velocity are mirrored. The biology is forced to adapt to a non-orientable universe.

## Implementation
- **Topology**: Figure-8 Immersion of the Klein Bottle.
- **Agents**: ChimeraVM instances executing genetic code.
- **Physics**: Movement in (u, v) parameter space with Mobius strip wrap-around logic.
