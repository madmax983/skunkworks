# Hyperbolic Quipu 🧶

A hybrid experiment combining **Poincaré Disk** visualization with **Incan Quipu** data structures.

This experiment visualizes the file system as an infinite Quipu hanging in Hyperbolic Space.

## Lineage
*   **Parent A:** `hyperbolic-finder` (Hyperbolic rendering engine)
*   **Parent B:** `quipu` (Inca data structure logic)

## Concept
In Euclidean space, a branching tree structure quickly runs out of space. In Hyperbolic space (represented by the Poincaré Disk), space expands exponentially as you move towards the edge. This allows for an "Infinite Quipu" where a single primary cord can support an exponential number of subsidiary cords without visual clutter.

## Features
*   **Hyperbolic Layout:** Cords are geodesic arcs.
*   **Quipu Data:** File sizes are represented as Knots on the cords.
*   **Navigation:** Drag to pan the view using Möbius transformations.

## Controls
*   **Left Click + Drag:** Pan the view.
