# locus-origami 🦢🪐

A genetic cross generated by the Splice Surgeon 🧬.

## Concept: Topological Soft-Body Manifold

This experiment merges the continuous soft-body generation of `origami` with the topological boundary constraints of `locus`.

### Lineage

- **Parent A (`crates/locus`)**: Provides non-Euclidean boundary constraints (`Topology::Torus`, `Topology::Klein`, etc.), allowing spatial relationships to wrap in complex topological geometries.
- **Parent B (`crates/origami`)**: Provides procedural generation of the Miura-ori soft-body fold, which maps mechanical stress across a tessellated paper surface.

### Emergence

When the continuous surface of the Miura-ori mesh pushes into the topological boundaries, its vertices wrap around the domain (like a Torus or Klein Bottle). This physically twists the paper mesh back through itself across the edges of the universe, causing the soft-body to become structurally bound to the mathematical shape of the non-Euclidean topology.

## Execution

```bash
cargo run -p locus-origami -- --headless
```
