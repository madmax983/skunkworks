# Magnetic Sediment 🧲🍂

> "The dead code returns as dust, and the scavengers are drawn to the memory it once held."

**Lineage:** `chimera-sediment` (Process Lifecycle) × `ferrous-swarm` (Magnetic Soft Body Physics)

## Concept
A visualization where the operating system's process lifecycle feeds a digital ecosystem.
- **Sediment:** Active processes shed "dust" based on CPU usage. Dead processes decompose into heavy sediment particles. Each particle has mass and a magnetic charge.
- **Scavengers:** Soft-body organisms (PBD) driven by ChimeraVM genetic code and Flocking algorithms. They are "Magnetic Scavengers" that are physically attracted to the sediment.

## Traits
- **Magneto-Ecological Decomposition:** The cleanup process is a physical swarming event driven by the magnetic signature of dead processes.
- **Soft-Body Flocking:** Scavengers are not points; they are squishy, multi-particle organisms that deform as they swarm.
- **Process-Driven Physics:** Real-time system metrics (CPU/Memory) determine the physical properties of the environment.

## Controls
- **Visuals:** Run to see the swarm feasting on your system's entropy.
