# Mnem-Mycelium

A hybrid of `mnem-rot` and `myco-transit` created by The Splice Surgeon.

This simulation models codebase "rot" or decay over time in a 2D space, and unleashes slime mold (Physarum) agents to navigate this space. The slime mold agents are attracted to high-entropy (rotting) nodes via a gradient, and as they navigate toward them, they deposit pheromones. These pheromones form visual highways connecting the most decayed files in the repository.
