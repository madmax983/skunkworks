# myco-ddos

## 🧬 Splice Lineage
This experiment is a hybrid cross between `locust-ddos` and `myco-transit`.

### Parent Alleles
- **From `locust-ddos`:** The macroscopic environment mechanics—agents targeting a central server, server health, and interacting with circular firewalls. The macroquad rendering loop and UI overlays.
- **From `myco-transit`:** The biological pathfinding and navigation logic—agents sensing a chemical gradient (pheromones) with three forward sensors, depositing trails as they move, and the environmental decay/diffusion of the pheromone substrate.

### Novel Phenotype
**Mycelial Cyberwarfare**
Instead of simple flocking or boid-like pathfinding, the swarm nodes function as a collective slime mold organism. When attacking the server, they forge highly efficient, branching highways through the firewalls by depositing and sensing pheromones. Successful paths are biologically reinforced and glow intensely, while blocked paths (agents killed by firewalls) naturally decay. The attack vector is an organic, self-optimizing mycelial web.
