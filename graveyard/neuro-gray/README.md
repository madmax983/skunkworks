# Neuromorphic Reaction-Diffusion (`neuro-gray`)

A hybrid organism born from the cross of `crates/neuro-sim` and `crates/gray-scott`.

## 🧬 Lineage

- **Parent A (`neuro-sim`)**: Provides a Spiking Neural Network (SNN) that simulates biological neuronal firings and network delays.
- **Parent B (`gray-scott`)**: Provides a continuous morphogenetic chemical reaction-diffusion substrate.

## 🔬 Phenotype

**Chemical Synaptic Diffusion:** This hybrid explores coupling a biological, discrete neural network with a continuous chemical reaction. Specifically, the electrical firing (spikes) of the Spiking Neural Network physically injects the "kill" chemical (Chemical V) into the Gray-Scott dish.

This creates an emergent dynamic where rapid, chaotic "thoughts" or neuronal firings disrupt and physically shape the biological Turing patterns forming around them. The neural network acts as a localized chemical injector, bridging the gap between electrical impulses and morphogenetic growth.
