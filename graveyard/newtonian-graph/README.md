# Newtonian Graph

Visualizes the dependency graph as a Newtonian N-body simulation.

Files are represented as bodies, where mass is proportional to the lines of code.
Dependencies create attractive forces (springs) between bodies.
All bodies repel each other to prevent overlap.

## Controls

| Key | Action |
| --- | --- |
| `Q` | Quit |
| `+` | Zoom In |
| `-` | Zoom Out |
| `↑` `↓` `←` `→` | Pan Camera |
| `R` | Reset View |
