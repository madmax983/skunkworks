# Rhythmic Jungle 🌴🥁

A hybrid experiment combining spatial agent simulation with Euclidean rhythms.

## Lineage

- **Parent A**: `experiments/protocol-jungle` (Spatial interactions, agent framework)
- **Parent B**: `experiments/silicon-samba` (Euclidean rhythm generation logic)

## Concept

Agents inhabit a 2D space (the "Jungle"). Each agent carries a rhythm (Euclidean pattern) and a tempo (BPM).
When agents meet, they "negotiate" a common groove by pulling each other's BPM and Pulse Density closer together.

- **Blue Agents**: Sparse rhythms (few pulses).
- **Red Agents**: Dense rhythms (many pulses).
- **Pulse**: Visual feedback when a beat occurs in the agent's rhythm.

## Emergent Behavior

Over time, local clusters of agents should synchronize their tempo and rhythm density, forming "Drum Circles".

## Controls

- Just watch the groove evolve.
