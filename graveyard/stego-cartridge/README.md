# ⚛️ Stego-Cartridge

**"The Cartridge is the Code."**

## Concept
Stego-Cartridge is a fantasy console where the game cartridges are simply PNG images. The game code (a custom bytecode) is steganographically embedded into the Least Significant Bits (LSB) of the image pixels. The image itself is procedurally generated from the code, creating a "Visual Cipher" where the program's logic dictates its aesthetic form.

## Moonshot
**LSB Steganography + Code Distribution**
- **Steganography:** Hiding executable code in pixel noise.
- **Visual Cipher:** The cover image is a unique visual fingerprint of the code it contains.

## Usage

### Build
```bash
cargo build --release
```

### Pack a Cartridge
Create an assembly file (e.g., `examples/noise.asm`) and pack it into a PNG:
```bash
cargo run --bin pack -- examples/noise.asm examples/noise.png
```

### Play a Cartridge
Run the console and load the PNG:
```bash
cargo run --bin stego-cartridge -- examples/noise.png
```
Or just run `cargo run` and drag-and-drop the PNG file onto the window.

## Architecture
- **VM:** A stack-based virtual machine with a 128x128 palette-indexed framebuffer.
- **Stego:** LSB encoding (1 bit per channel = 4 bits per pixel).
- **Asm:** A simple assembler for the VM instructions.
- **Visuals:** `macroquad` for the console display.

## Instruction Set
- `PUSH <val>`: Push value to stack
- `POP`: Pop value
- `ADD`, `SUB`, `MUL`, `DIV`, `MOD`: Arithmetic
- `JMP <label>`: Jump to label
- `JZ <label>`: Pop and jump if zero
- `JNZ <label>`: Pop and jump if not zero
- `LOAD`, `STORE`: Memory access
- `PLOT`: Draw pixel (x, y, color)
- `CLS`: Clear screen
- `RND`: Push random number
- `WAIT`: Wait for next frame
- `DUP`: Duplicate top of stack
- `HALT`: Stop execution
