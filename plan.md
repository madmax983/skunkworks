1. **Survey:** In `experiments/chimera-lang/src/vm/nova_genetics.rs`, `nova_egregore.rs`, and `nova_fractal.rs`, there are many functions using `.unwrap()` on `stack.pop()`. E.g., `let s_val = vm.stack.pop().unwrap();`. While they are guarded by `if vm.stack.len() >= N`, `.unwrap()` is considered dangerous because refactoring could misalign the check and the pop.
2. **Select:** I will refactor `experiments/chimera-lang/src/vm/nova_genetics.rs` (32 unwraps), `nova_egregore.rs` (4 unwraps), and `nova_fractal.rs` (11 unwraps) to remove `.unwrap()`.
3. **Refactor Phase:** Replace guarded `.unwrap()` calls with `?` or `let Some(...) = ... else { return None; }`. For functions returning `Option<(usize, usize)>` where `unwrap()` is currently used, I can replace `let x = vm.stack.pop().unwrap();` with `let Some(x) = vm.stack.pop() else { return None; };` or simply `let x = vm.stack.pop()?;`. The `?` operator is extremely clean here. I will use `?` where possible, or safe `if let Some(x) = vm.stack.pop()` when inside a larger loop or where `?` isn't suitable. Given Forge's learning states: "When popping from a stack in a function returning `Option`, use the `?` try operator." I will follow that.
4. **Pre-commit:** Run tests, `cargo clippy`, and `cargo fmt`.
